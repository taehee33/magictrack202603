# MagicMagicTrack 설치 가이드

MagicMagicTrack을 설치하고 처음 실행할 때 필요한 절차입니다.

지금 배포본은 Apple Developer ID 서명·공증 없이 배포합니다. 그래서 처음 열 때 한 번 macOS 보안 경고가 나옵니다. 아래 3장대로 허용하면 그다음부터는 바로 열립니다.

## 1. 다운로드

[Releases](https://github.com/taehee33/magictrack202603/releases/latest)에서 아래 파일 중 하나를 받습니다.

- 권장: `MagicMagicTrack-버전.dmg`
- 대안: `MagicMagicTrack-버전-macOS.zip`
- `SHA256.txt`: 받은 파일이 바뀌지 않았는지 확인할 때 씁니다 (선택)

```bash
shasum -a 256 ~/Downloads/MagicMagicTrack-*.dmg
```

출력된 값이 `SHA256.txt`의 값과 같으면 정상입니다.

## 2. 설치

### DMG

1. `.dmg` 파일을 더블클릭합니다.
2. 열린 창에서 `MagicMagicTrack.app`을 `응용 프로그램`(Applications) 폴더로 끌어 놓습니다.

### ZIP

1. `.zip` 파일을 더블클릭해 압축을 풉니다.
2. `MagicMagicTrack.app`을 `응용 프로그램` 폴더로 옮깁니다.

꼭 `응용 프로그램` 폴더로 옮긴 뒤 실행하세요. 다운로드 폴더에서 바로 실행하면 권한이 제대로 유지되지 않을 수 있습니다.

예전 `MagicTrack.app`이 있으면 지워 주세요. 설정·프리셋·앱 규칙은 그대로 이어집니다.

## 3. 처음 열기 ("확인되지 않은 개발자" 경고)

1. `응용 프로그램` 폴더에서 `MagicMagicTrack.app`을 더블클릭합니다.
2. "Apple은 'MagicMagicTrack'에 악성 코드가 없음을 확인할 수 없습니다" 같은 경고가 나오면 **완료**(또는 취소)를 누릅니다.
3. **시스템 설정 › 개인정보 보호 및 보안**을 열고 아래로 스크롤합니다.
4. "'MagicMagicTrack'이(가) 차단되었습니다" 옆의 **그래도 열기**를 누릅니다.
5. 암호 또는 Touch ID로 확인하고, 다시 나오는 창에서 **그래도 열기**를 누릅니다.

한 번 허용하면 다음부터는 바로 열립니다.

> macOS 15 이후로는 예전처럼 앱을 우클릭 › 열기로 경고를 넘길 수 없습니다. 시스템 설정의 **그래도 열기**를 써 주세요.

### "손상되었기 때문에 열 수 없습니다"가 나올 때

인터넷에서 받은 파일에 붙는 격리 표시 때문에 나올 수 있습니다. 앱을 `응용 프로그램` 폴더로 옮긴 뒤 터미널에서 아래 명령을 실행하고 다시 엽니다.

```bash
xattr -dr com.apple.quarantine /Applications/MagicMagicTrack.app
```

## 4. 권한

| 기능 | 필요한 권한 |
|---|---|
| 속도·스크롤·클릭 압력, 자동 전환, 앱 규칙, 180° 회전 | 없음 |
| 매직 트랙패드 왼쪽·오른쪽 90° 회전 | 손쉬운 사용 |

90° 회전을 켰는데 권한이 없으면 매직 트랙패드 카드에 안내가 나옵니다.

1. 카드의 **권한 열기**를 누릅니다. (또는 **시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용**)
2. 목록에서 `MagicMagicTrack`을 켭니다.

허용하면 앱을 다시 시작하지 않아도 바로 동작합니다. 목록에 `MagicMagicTrack`이 여러 개 있으면 예전 항목은 지워도 됩니다.

## 5. 기본 사용법

### 트랙패드 탭

- 내장 트랙패드와 매직 트랙패드 카드가 나란히 보입니다.
- 카드마다 이동 속도·스크롤 속도·클릭 압력을 정합니다. 바꾸는 즉시 적용됩니다.
- **전환 모드**: 자동(손가락이 닿은 트랙패드의 설정으로 전환) / 내장 고정 / 매직 고정
- 매직 트랙패드 카드에서 회전(없음 · 180° · 왼쪽 90° · 오른쪽 90°)을 고릅니다.
- 항목마다 '내 기본값' 또는 'Mac 기본값'으로 되돌릴 수 있습니다.

### 프리셋 탭

- 지금 설정을 프리셋으로 저장하고, 편집·복제·삭제합니다.
- **앱 규칙**: 특정 앱을 쓸 때 정한 프리셋을 자동으로 적용합니다.

### 설정 탭

- 로그인 시 자동 시작, Dock·메뉴바 표시, 메뉴바에 사용 중인 트랙패드와 회전 표시
- 언어(한국어 / English)
- 전환 모드 단축키 (기본 `⌃⌥M`, 바꾸거나 끌 수 있음)
- 새 버전 확인

### 메뉴바

메뉴바 아이콘 옆에 지금 쓰는 트랙패드와 회전이 `내장`, `매직 좌 90°`처럼 표시됩니다. 누르면 전환 모드와 프리셋을 바로 바꿀 수 있습니다.

**시스템 설정 값은 바꾸지 않습니다.** 앱이 켜져 있는 동안 실행 중인 값만 덮어쓰고, 앱을 끄면 시스템 설정 값으로 돌아갑니다.

## 6. 알려진 한계

- macOS 비공개 기능을 씁니다. macOS 업데이트 후 일부 기능이 멈출 수 있습니다. 자동 전환을 쓸 수 없으면 고정 모드로 동작합니다.
- 90° 회전에서 두 손가락 페이지 넘기기(뒤로·앞으로)는 회전되지 않습니다.
- macOS 14 이상에서 설치할 수 있지만 테스트는 macOS 27에서만 했습니다.

## 7. 문제 해결 체크리스트

1. `응용 프로그램` 폴더로 옮긴 뒤 실행했나요?
2. **개인정보 보호 및 보안 › 그래도 열기**를 눌렀나요?
3. "손상되었기 때문에 열 수 없습니다"가 나오면 3장의 `xattr` 명령을 실행했나요?
4. 90° 회전이 안 되면 **손쉬운 사용**에서 `MagicMagicTrack`을 켰나요?
5. 그래도 안 되면 메뉴바 아이콘 › 종료 후 다시 실행해 보세요.

문제를 알릴 때는 설정 탭 › 고급 › **개발자 모드**를 켜면 트랙패드 탭 아래에 장치·전환 기록이 보입니다. 이 화면을 캡처해 [Issues](https://github.com/taehee33/magictrack202603/issues)에 올려 주세요.

## 8. 자주 묻는 질문

### 왜 처음에 경고가 나오나요?

Apple Developer ID 서명과 공증 없이 배포해서 macOS가 개발자를 확인할 수 없기 때문입니다. 한 번 허용하면 다음부터는 나오지 않습니다.

### 악성 앱인가요?

아닙니다. 소스 코드가 모두 [GitHub](https://github.com/taehee33/magictrack202603)에 공개되어 있고, 직접 빌드해서 쓸 수도 있습니다.

### Mac App Store에는 왜 없나요?

비공개 macOS 기능과 샌드박스 밖 동작이 필요해서 App Store 규정상 낼 수 없습니다.
