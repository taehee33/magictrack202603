# MagicTrack v1.1.1 (build 3) — 안정화

## 고친 문제
- **앱을 켜면 마지막으로 쓰던 트랙패드 설정이 바로 적용돼요.** 전에는 켤 때마다 '선택 없음'이었어요. 이 상태에서는 프리셋과 앱 자동전환이 이동·스크롤 속도를 적용하지 않았어요.
- **클릭 압력이 바로 적용돼요.** 시스템 설정 앱과 같은 방식으로 적용해요. 전에는 설정 파일에만 저장돼서 실제로는 바뀌지 않았어요.
- **스크롤 속도가 트랙패드에만 적용돼요.** 전에는 마우스 휠 설정도 같이 바뀌었어요.
- **낮은 속도값이 재실행할 때마다 커지던 문제를 고쳤어요.** 예전 0~3 단위를 0~10으로 바꾸는 변환이 실행할 때마다 다시 돌았어요. 이미 커진 값은 되돌릴 수 없으니 확인 후 다시 설정해 주세요.
- **'일반' 프리셋을 고쳐도 되돌아가던 문제와, 속도를 0으로 저장할 수 없던 문제를 고쳤어요.**
- **이름을 바꾼 매직 트랙패드도 알아봐요.** 이름 대신 장치 정보(내장 여부, 장치 종류, 제조사·제품 번호)로 판별해요. USB-C 매직 트랙패드(0x0324)와 블루투스 제조사 번호(0x004C)도 인식해요.
- **⌥M을 한 번 누르면 한 번만 전환돼요.** 앱이 앞에 있을 때 두 번 전환되던 문제를 고쳤어요.
- 연결한 트랙패드가 끊기면 다른 트랙패드 설정으로 바뀌고, 다시 연결되면 마지막으로 고른 설정으로 돌아가요.

## 바뀐 점
- **입력 모니터링 권한이 필요 없어요.** 트랙패드 입력을 읽지 않고, 장치 목록과 연결 알림만 사용해요.
- 슬라이더를 움직여도 터미널 명령을 실행하지 않아서 앱이 멈추지 않아요.
- 처음 실행할 때 '일반' 프리셋으로 macOS 설정을 덮어쓰지 않아요.
- 쓰지 않는 권한 설명(Info.plist)과 잘못된 엔타이틀먼트 키를 정리했어요.

## 그대로인 것
- 디버그 패널은 그대로 보여요. 입력을 읽지 않으므로 VALUE·REPORT 카운터는 0으로 남아요.
- 회전은 아직 저장만 돼요. v1.2에서 구현할 예정이에요.
