# MagicMagicTrack v1.4.1 (build 7) — 90° 포인터 끊김·외부 모니터 떨림 수정

## 고친 문제
- **90° 회전에서 포인터가 이동 중 조금씩 튀던 문제**: 커서를 손가락 센서 프레임 사이로 이어 그리는데, 다음 프레임이 오기 전에 그릴 시각이 앞서 나가 커서가 잠깐 멈췄다가 한꺼번에 따라갔어요. 블루투스가 프레임을 두 개씩 붙여 보낼 때 특히 심했어요. 이제 프레임이 실제로 도착하는 간격을 보고 그리는 시점을 자동으로 맞춰요.
- **외부 모니터에서 90° 포인터가 떨리던 문제**: 커서를 그리는 박자가 손가락을 처음 올린 화면에 고정돼 있어서, 주사율이 다른 모니터로 넘어가면 맞지 않았어요. 이제 커서가 있는 화면의 주사율(60Hz·120Hz 등)에 맞춰 그리고, 화면 갱신 시각을 기준으로 계산해서 간격이 고르게 유지돼요.
- **손가락을 뗄 때 커서가 툭 튀던 문제**: 남은 이동을 한 번에 옮기지 않고 마저 부드럽게 그려요.
- **커서가 잠깐 이전 위치로 되돌아가던 문제**: macOS 이동 이벤트가 커서를 옮긴 직후에 적용돼 커서를 직전 위치로 되돌리는 경우가 있었어요. 이제 바로 바로잡아요.

실측: 커서가 다음 센서 프레임을 기다리며 멈춘 화면 갱신 비율 — 내장 화면 7.2% → 1.3%, 120Hz 외부 모니터 7.9% → 0.7%, 60Hz 외부 모니터 22.4% → 2.1%.

## 업데이트할 때 알아둘 점
- v1.4.0에서 업데이트하면 손쉬운 사용 권한이 그대로 유지돼요 (같은 인증서로 서명).
- v1.3.0 이하에서 업데이트하면 90° 회전을 위해 손쉬운 사용 권한을 한 번 다시 허용해 주세요.
- 설정·프리셋·앱 규칙은 그대로 이어져요.

## 알려진 한계
- 90° 회전에서 커서는 손가락보다 약 30ms 늦게 따라와요 (센서 프레임 사이를 이어 그리느라 생기는 지연).
- 비공개 macOS 기능을 사용해요. macOS 업데이트로 바뀌면 일부 기능이 멈출 수 있어요.
- macOS 14 이상에서 설치할 수 있지만 테스트는 macOS 27에서만 했어요.
