# MagicMagicTrack v1.2.0

맥북 내장 트랙패드와 매직 트랙패드의 이동 속도·스크롤·클릭 압력을 **따로** 정하고, 매직 트랙패드를 **돌려 놓고** 쓸 수 있게 해 주는 macOS 앱이에요. 이번 버전부터 이름이 MagicTrack에서 **MagicMagicTrack**으로 바뀌었어요.

## 주요 기능
- **만진 트랙패드로 자동 전환**: 손가락이 닿은 트랙패드의 설정이 바로 적용돼요. 권한이 필요 없어요.
- **전환 모드**: 자동 / 내장 고정 / 매직 고정. 단축키 **⌃⌥M**으로 순환해요 (설정에서 바꾸거나 끌 수 있음).
- **매직 트랙패드 회전**: 180°(권한 없음), 왼쪽·오른쪽 90°(손쉬운 사용 권한 필요, 제스처는 회전되지 않음).
- **시스템 설정과 같은 속도 칸**: 이동 10칸, 스크롤 8칸.
- **기본값 두 가지**: 항목마다 '내 기본값'과 'Mac 기본값'으로 되돌리기.
- **프리셋**: 편집·복제·삭제, 지금 값이 프리셋과 다르면 '수정됨' 표시. 앱마다 프리셋을 자동 적용하는 앱 규칙.
- **시스템 설정 값을 바꾸지 않아요**: 앱을 끄면 원래 시스템 값으로 돌아가요.
- 새 아이콘, 지금 쓰는 트랙패드를 보여주는 메뉴바 아이콘, 설정을 한 곳에 모은 설정 탭.

자세한 변경 내용은 [릴리즈 노트](https://github.com/taehee33/magictrack202603/blob/main/docs/release/release-notes-v1.2.0.md)를 참고하세요.

## v1.1에서 업데이트하는 경우
- **단축키가 ⌥M에서 ⌃⌥M으로 바뀌었어요.** 설정 탭에서 다시 바꿀 수 있어요.
- **앱 이름이 바뀌었어요.** `응용 프로그램` 폴더에 있는 예전 `MagicTrack.app`은 지워 주세요. 설정·프리셋·앱 규칙은 그대로 이어져요.
- 저장된 속도 값은 시스템 설정과 같은 칸으로 한 번 변환돼요. 업데이트 후 값을 한 번 확인해 주세요.

## 설치
1. `MagicMagicTrack-1.2.0-4.dmg`를 열고 `MagicMagicTrack.app`을 `응용 프로그램` 폴더로 끌어다 놓아요. (dmg가 안 되면 zip을 풀어서 옮겨도 돼요.)
2. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면: **시스템 설정 › 개인정보 보호 및 보안**으로 가서 MagicMagicTrack 옆의 **그래도 열기**를 누른 뒤 다시 열어요.

이 버전은 Apple Developer ID 서명과 공증(notarization)을 거치지 않아서 처음 한 번 위 경고가 나와요.

## 요구 사항
- macOS 14 이상
- 매직 트랙패드 기능은 블루투스 또는 USB로 연결된 매직 트랙패드 필요

## 알려진 한계
- 비공개 macOS 기능을 사용해요. macOS 업데이트 후 자동 전환을 쓸 수 없으면 고정 모드로 동작해요.
- 90° 회전 중에는 매직 트랙패드를 쓰는 동안 커서를 앱이 직접 움직여요.
