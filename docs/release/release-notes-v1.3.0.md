# MagicMagicTrack v1.3.0 (build 5) — 영어 · 쓸어넘기기 회전 · 회전 표시

## 새 기능
- **영어 지원**: 설정 탭 › 언어에서 한국어 / English를 고를 수 있어요. 기본은 시스템 언어와 상관없이 한국어예요. 바꾸면 '지금 다시 시작'으로 적용돼요.
- **90° 회전에서 세·네 손가락 쓸어넘기기도 회전**: 데스크톱 전환과 Mission Control이 매직 트랙패드를 돌려 놓은 방향 그대로 동작해요. 맥북 트랙패드에서 같은 방향으로 쓸었을 때와 같은 동작이에요.
- **회전 상태 표시**: 매직 트랙패드 카드의 아이콘이 설정한 방향만큼 돌아가고, 상태 옆에 '· 180° 회전', '· 왼쪽 90° 회전'처럼 표시돼요.
- **메뉴바에 지금 쓰는 트랙패드 표시**: 메뉴바 아이콘 옆에 '내장', '매직', '매직 좌 90°'처럼 글자로 보여줘요. 설정 탭 › 시작에서 끌 수 있어요.

## 고친 문제
- **90° 회전 중 마우스 휠이 가로로 바뀌던 문제**: Logi Options+처럼 휠 스크롤을 다시 보내는 앱을 쓰면, 매직 트랙패드로 스크롤한 뒤 MX Master 같은 마우스 휠까지 회전돼 세로 휠이 가로로 움직였어요. 이제 마우스 휠은 회전하지 않아요.

## 바뀐 점
- **고정 인증서로 서명해요**: 이번 버전부터 같은 인증서로 서명해서, **다음 업데이트부터는 손쉬운 사용 권한을 다시 허용하지 않아도 돼요.**
- README를 새로 쓰고 영어 README와 스크린샷을 추가했어요.

## 업데이트할 때 알아둘 점
- **90° 회전을 쓰고 있다면 손쉬운 사용 권한을 한 번 다시 허용해 주세요.** v1.2.0과 서명 방식이 달라 macOS가 새 앱으로 봐요. 매직 트랙패드 카드의 '권한 열기'를 누르거나 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 MagicMagicTrack을 켜면 돼요. 목록에 MagicMagicTrack이 여러 개 있으면 예전 항목은 지워도 돼요.
- 설정·프리셋·앱 규칙은 그대로 이어져요.

## 알려진 한계
- 90° 회전에서 두 손가락 페이지 넘기기(뒤로·앞으로)는 회전되지 않아요. 핀치처럼 방향과 상관없는 제스처는 그대로 동작해요.
- 비공개 macOS 기능(MultitouchSupport, 시스템 설정 내부 기능, 이벤트 비공개 필드, SkyLight)을 사용해요. macOS 업데이트로 바뀌면 일부 기능이 멈출 수 있어요.
- macOS 14 이상에서 설치할 수 있지만 테스트는 macOS 27에서만 했어요.
