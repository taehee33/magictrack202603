# MagicMagicTrack v1.4.0 (build 6) — 두 손가락 페이지 넘기기 · 부드러운 90° 포인터 · 새 버전 확인

## 새 기능
- **90° 회전에서 두 손가락 페이지 넘기기(뒤로·앞으로)도 회전**: 매직 트랙패드를 돌려 놓은 방향 그대로 Safari와 Chrome에서 두 손가락으로 쓸어 뒤로·앞으로 갈 수 있어요.
- **새 버전 확인**: GitHub의 최신 릴리스를 하루 한 번 확인해서, 새 버전이 있으면 설정 탭과 메뉴바에 알려 줘요. 설정 탭 › 업데이트에서 끄거나 '지금 확인'을 누를 수 있어요. 자동으로 내려받거나 설치하지는 않아요.
- **손쉬운 사용 권한 확인·다시 등록**: 설정 탭 › 권한에서 허용 상태를 보고, 권한이 꼬였을 때 '권한 다시 등록…'으로 처음부터 다시 허용할 수 있어요. '앱 위치 보기'로 지금 실행 중인 앱이 어디 있는지도 볼 수 있어요.
- **화면 모드**: 설정 탭 › 화면 모드에서 시스템 설정에 맞춤 / 라이트 / 다크를 고를 수 있어요. 기본은 시스템 설정에 맞춤이에요.

## 고친 문제
- **90° 회전에서 포인터가 떨리고 끊기던 문제**: 천천히 움직이면 커서가 멈췄다가 한꺼번에 움직이며 떨렸어요. 이제 손가락 센서 신호에 맞춰 커서를 움직이고, 화면 주사율(ProMotion)에 맞춰 그려서 내장 트랙패드처럼 부드럽게 움직여요. 손가락을 처음 올릴 때 커서가 튀던 문제도 고쳤어요.
- **90° 회전에서 스크롤이 어색하던 문제**: 스크롤을 새로 만들어 보내지 않고 원래 스크롤의 방향만 돌려서, macOS의 가속과 관성이 그대로 살아 있어요.

## 바뀐 점
- **서명을 자체 인증서로 바꿨어요**: 이전 버전은 개발자 인증서로 서명해서 앱 서명 정보에 개발자 이메일이 들어 있었어요. 이번 버전부터는 'MagicMagicTrack' 자체 인증서로 서명해요. 앞으로도 같은 인증서를 쓰므로, 다음 업데이트부터는 권한이 유지돼요.
- 설치 가이드와 배포 문서를 지금 앱에 맞게 다시 썼어요.

## 업데이트할 때 알아둘 점
- **90° 회전을 쓰고 있다면 손쉬운 사용 권한을 한 번 다시 허용해 주세요.** 서명 인증서가 바뀌어 macOS가 새 앱으로 봐요. 설정 탭 › 권한의 '허용하기'를 누르거나 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 MagicMagicTrack을 켜면 돼요. 잘 안 되면 '권한 다시 등록…'을 눌러 주세요.
- 설정·프리셋·앱 규칙은 그대로 이어져요.

## 알려진 한계
- 비공개 macOS 기능(MultitouchSupport, 시스템 설정 내부 기능, 이벤트 비공개 필드, SkyLight)을 사용해요. macOS 업데이트로 바뀌면 일부 기능이 멈출 수 있어요.
- 90° 회전 중에는 매직 트랙패드를 쓰는 동안 커서를 앱이 직접 움직여요.
- macOS 14 이상에서 설치할 수 있지만 테스트는 macOS 27에서만 했어요.
