# MagicMagicTrack v1.4.1

맥북 내장 트랙패드와 매직 트랙패드의 이동 속도·스크롤·클릭 압력을 **따로** 정하고, 매직 트랙패드를 **돌려 놓고** 쓸 수 있게 해 주는 macOS 앱이에요.

## 고친 문제
- 90° 회전에서 포인터가 이동 중 조금씩 튀던 문제
- 외부 모니터(특히 60Hz)에서 90° 포인터가 떨리던 문제: 이제 커서가 있는 화면의 주사율에 맞춰 그려요
- 손가락을 뗄 때 커서가 툭 튀던 문제, 커서가 잠깐 이전 위치로 되돌아가던 문제

자세한 내용은 [릴리즈 노트](https://github.com/taehee33/magictrack202603/blob/main/docs/release/release-notes-v1.4.1.md)를 참고하세요.

## 이전 버전에서 업데이트하는 경우
- v1.4.0에서 업데이트하면 손쉬운 사용 권한이 그대로 유지돼요.
- v1.3.0 이하에서 업데이트하면 **90° 회전을 위해 손쉬운 사용 권한을 한 번 다시 허용**해 주세요 (설정 탭 › 권한의 '허용하기'). 잘 안 되면 '권한 다시 등록…'을 눌러 주세요.
- 설정·프리셋·앱 규칙은 그대로 이어져요.

## 설치
1. `MagicMagicTrack-1.4.1-7.dmg`를 열고 `MagicMagicTrack.app`을 `응용 프로그램` 폴더로 옮겨요. (dmg가 안 되면 zip을 풀어서 옮겨도 돼요.)
2. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면 **시스템 설정 › 개인정보 보호 및 보안**에서 **그래도 열기**를 눌러요. ([설치 가이드](https://github.com/taehee33/magictrack202603/blob/main/docs/install/install-guide-ko.md))

Apple Developer ID 서명·공증 없이 배포해서 처음 한 번 위 경고가 나와요.

## 필요한 권한
- 왼쪽·오른쪽 90° 회전에만 손쉬운 사용 권한이 필요해요. 다른 기능은 권한 없이 동작해요.

## 요구 사항
- macOS 14 이상 (macOS 27에서 테스트)
- 매직 트랙패드 기능은 블루투스 또는 USB로 연결된 매직 트랙패드 필요

## 알려진 한계
- 비공개 macOS 기능을 사용해요. macOS 업데이트 후 일부 기능이 멈출 수 있어요.
- 90° 회전 중에는 매직 트랙패드를 쓰는 동안 커서를 앱이 직접 움직이고, 손가락보다 약 30ms 늦게 따라와요.
