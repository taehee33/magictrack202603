# MagicMagicTrack v1.3.0

맥북 내장 트랙패드와 매직 트랙패드의 이동 속도·스크롤·클릭 압력을 **따로** 정하고, 매직 트랙패드를 **돌려 놓고** 쓸 수 있게 해 주는 macOS 앱이에요.

## 새 기능
- **영어 지원**: 설정 탭 › 언어에서 한국어 / English 선택 (기본 한국어)
- **90° 회전에서 세·네 손가락 쓸어넘기기도 회전**: 데스크톱 전환과 Mission Control이 돌려 놓은 방향 그대로 동작
- **회전 상태 표시**: 카드 아이콘이 방향만큼 돌아가고 '· 180° 회전'처럼 표시
- **메뉴바에 지금 쓰는 트랙패드 표시**: '내장', '매직 좌 90°'처럼 글자로 (끌 수 있음)

## 고친 문제
- 90° 회전 중 Logi Options+ 같은 앱을 쓰는 마우스 휠(예: MX Master)이 가로로 바뀌던 문제

## 바뀐 점
- 고정 인증서로 서명해서 **다음 업데이트부터 손쉬운 사용 권한이 유지**돼요.

자세한 내용은 [릴리즈 노트](https://github.com/taehee33/magictrack202603/blob/main/docs/release/release-notes-v1.3.0.md)를 참고하세요.

## v1.2.0에서 업데이트하는 경우
- **90° 회전을 쓰고 있다면 손쉬운 사용 권한을 한 번 다시 허용**해 주세요. 매직 트랙패드 카드의 '권한 열기' 또는 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용.
- 설정·프리셋·앱 규칙은 그대로 이어져요.

## 설치
1. `MagicMagicTrack-1.3.0-5.dmg`를 열고 `MagicMagicTrack.app`을 `응용 프로그램` 폴더로 옮겨요. (dmg가 안 되면 zip을 풀어서 옮겨도 돼요.)
2. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면 **시스템 설정 › 개인정보 보호 및 보안**에서 **그래도 열기**를 눌러요.

Apple Developer ID 서명·공증 없이 배포해서 처음 한 번 위 경고가 나와요.

## 요구 사항
- macOS 14 이상 (macOS 27에서 테스트)
- 매직 트랙패드 기능은 블루투스 또는 USB로 연결된 매직 트랙패드 필요

## 알려진 한계
- 90° 회전에서 두 손가락 페이지 넘기기(뒤로·앞으로)는 회전되지 않아요.
- 비공개 macOS 기능을 사용해요. macOS 업데이트 후 일부 기능이 멈출 수 있어요.
