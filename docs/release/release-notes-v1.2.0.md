# MagicMagicTrack v1.2.0 (build 4) — 자동 전환 · 회전 · 새 이름

MagicTrack이 **MagicMagicTrack**으로 이름이 바뀌었어요. 설정·프리셋·앱 규칙은 그대로 이어져요.

## 새 기능
- **만진 트랙패드로 자동 전환**: 손가락이 닿은 트랙패드(내장/매직)의 이동 속도·스크롤·클릭 압력이 바로 적용돼요. 권한이 필요 없어요.
- **전환 모드**: 자동 / 내장 고정 / 매직 고정. 트랙패드 탭 위쪽 '전환 모드'나 메뉴바에서 고르거나 단축키로 순환해요.
- **전환 단축키를 바꾸거나 끌 수 있어요**: 기본값은 **⌃⌥M**이에요. 설정 탭 › 트랙패드 전환에서 다른 조합을 지정하거나 끌 수 있어요. 다른 앱이 이미 쓰는 조합이면 알려줘요.
- **전환 알림**: 트랙패드나 모드가 바뀌면 화면 아래에 잠깐 표시돼요 (설정에서 끌 수 있음).
- **매직 트랙패드 회전**
  - 180°: 트랙패드 펌웨어가 직접 뒤집어 포인터·스크롤·제스처가 모두 바뀌어요. 권한이 필요 없어요.
  - 왼쪽·오른쪽 90°: 포인터·클릭·드래그·스크롤이 회전돼요. 손쉬운 사용 권한이 필요하고, 스와이프·핀치 같은 제스처는 회전되지 않아요.
- **시스템 설정과 같은 속도 칸**: 이동 속도 10칸, 스크롤 속도 8칸이 시스템 설정과 같은 값이에요.
- **기본값 되돌리기 두 가지**: 항목마다 '내 기본값'(직접 저장한 값)과 'Mac 기본값'(이동 4칸 · 스크롤 4칸 · 클릭 보통) 중에 골라 되돌려요. 카드의 ⋯ 메뉴에서 한 번에 되돌리거나 지금 값을 내 기본값으로 저장할 수 있어요.
- **프리셋 편집**: 이름·이모지·두 트랙패드 값·매직 회전을 고칠 수 있어요. 카드의 ⋯ 메뉴에서 편집·복제·삭제해요.
- **'수정됨' 표시**: 지금 값이 적용 중인 프리셋과 다르면 트랙패드 카드에 '수정됨'이 붙어요.

## 바뀐 점
- **새 앱 아이콘**: 겹친 두 트랙패드(파랑 = 내장, 보라 = 매직). macOS 26에서는 Liquid Glass 아이콘으로 보여요.
- **메뉴바 아이콘이 지금 쓰는 트랙패드를 보여줘요**: 적용 중인 트랙패드 쪽이 채워져요.
- **설정이 한 곳에 모였어요**: 별도 설정 창 대신 메인 창 '설정' 탭에 모두 있어요. ⌘,도 이 탭을 열어요.
- **트랙패드 탭 단순화**
  - 두 트랙패드 카드를 나란히 보여줘요 (창이 좁으면 위아래).
  - 빠른 전환 버튼과 카드의 '이 설정 적용' 버튼을 없앴어요. 둘 다 고정 모드로 바꾸는 동작이라 모르는 사이 자동 전환이 꺼졌어요. 전환은 '전환 모드' 하나로 해요.
  - 상태는 '사용 중 / 연결됨 / 연결 없음'으로 통일했어요.
  - 장치·전환 로그는 설정 탭 › 고급 › 개발자 모드를 켰을 때만 보여요.
- **시스템 설정 값을 바꾸지 않아요**: 실행 중인 값만 덮어쓰고, 앱을 끄면 원래 시스템 값으로 돌아가요. 비정상 종료 후 다시 켜도 복구해요.
- **앱 규칙**: 프리셋을 지울 때 그 프리셋을 쓰는 앱 규칙을 같이 지울지 물어봐요. 프리셋이 없어진 규칙은 경고하고 바로 다시 고를 수 있어요. 메뉴바에 프리셋이 모두 보여요.
- **로그인 시 자동 시작** 토글이 실제 macOS 상태를 보여줘요. 시스템 설정에서 꺼도 맞게 보여요.
- '모든 프리셋 초기화'에 확인 창이 생겼고, 시트에서 Enter·Esc가 동작해요.

## 업데이트할 때 알아둘 점
- **단축키가 ⌥M에서 ⌃⌥M으로 바뀌었어요.** ⌥M은 영문 입력(µ)과 다른 앱의 단축키를 가로챘어요. 예전처럼 쓰려면 설정 탭에서 다시 지정할 수 있어요.
- **앱 파일 이름이 `MagicMagicTrack.app`으로 바뀌었어요.** `응용 프로그램` 폴더에 있는 예전 `MagicTrack.app`은 지워 주세요.
- 저장된 속도 값은 시스템 설정과 같은 칸으로 한 번 변환돼요. 변환 후 값을 한 번 확인해 주세요.

## 알려진 한계
- 비공개 macOS 기능(MultitouchSupport, 시스템 설정 백엔드, 이벤트 비공개 필드)을 사용해요. macOS 업데이트 후 자동 전환을 쓸 수 없으면 고정 모드로 동작해요.
- 90° 회전 중에는 매직 트랙패드를 쓰는 동안 커서를 앱이 직접 움직여요.
