# MagicTrack v1.2.0 (build 4) — 자동 전환 · 회전

## 새 기능
- **만진 트랙패드로 자동 전환**: 손가락이 닿은 트랙패드(내장/매직)의 이동 속도·스크롤·클릭 압력이 바로 적용돼요. 권한이 필요 없어요.
- **전환 모드**: 자동 / 내장 고정 / 매직 고정. 메인 창·메뉴바에서 고르거나 ⌥M으로 순환해요.
- **전환 알림**: 트랙패드나 모드가 바뀌면 화면 아래에 잠깐 표시돼요 (설정에서 끌 수 있음).
- **매직 트랙패드 회전**
  - 180°: 트랙패드 펌웨어가 직접 뒤집어 포인터·스크롤·제스처가 모두 바뀌어요. 권한이 필요 없어요.
  - 왼쪽·오른쪽 90°: 포인터·클릭·드래그·스크롤이 회전돼요. 손쉬운 사용 권한이 필요하고, 스와이프·핀치 같은 제스처는 회전되지 않아요.

## 개선
- 자동 전환 시 이동 속도는 즉시(0.1ms 미만), 스크롤·클릭 압력은 백그라운드에서 적용해 입력이 밀리지 않아요.
- 디버그 패널이 터치 감지·전환 기록을 보여줘요.

## 알려진 한계
- 비공개 macOS 기능(MultitouchSupport, 시스템 설정 백엔드, 이벤트 비공개 필드)을 사용해요. macOS 업데이트 후 자동 전환을 쓸 수 없으면 고정 모드로 동작해요.
- 90° 회전 중에는 매직 트랙패드를 쓰는 동안 커서를 앱이 직접 움직여요.
